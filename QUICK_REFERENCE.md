## 🎯 Common Commands

### Generate Synthetic Data Only
```bash
python -c "
from preprocessing.synthetic_generator import VANETAttackGenerator
gen = VANETAttackGenerator()
data = gen.generate_balanced_dataset(1000)
gen.save_synthetic_data(data, 'my_data.csv')

```

### Train CNN-LSTM Model
```bash
python train_model.py \
    --model cnn_lstm \
    --generate_synthetic \
    --samples_per_class 2000 \
    --epochs 50 \
    --batch_size 64
```

### Train Autoencoder Only
```bash
python train_model.py \
    --model autoencoder \
    --generate_synthetic \
    --epochs 30
```

### Train Both Models
```bash
python train_model.py \
    --model both \
    --generate_synthetic \
    --samples_per_class 1000
```

## 📊 Attack Types

| Attack | Key Indicators | Generated By |
|--------|---------------|--------------|
| **DoS** | High packet loss (>50%)<br>High latency (>1000ms)<br>High congestion (>0.8) | `generate_dos_attack()` |
| **Sybil** | High router count (>5)<br>Identity spoofing<br>Normal traffic patterns | `generate_sybil_attack()` |
| **Wormhole** | Low latency (<50ms)<br>Low router count (<3)<br>Route anomalies | `generate_wormhole_attack()` |
| **Normal** | Typical network metrics<br>No anomalies | `generate_normal_traffic()` |

## 🐛 Troubleshooting

### ImportError: No module named 'tensorflow'
```bash
pip install tensorflow
# Or for CPU only:
pip install tensorflow-cpu
```

### CUDA/GPU Errors
```bash
# Use CPU only
export CUDA_VISIBLE_DEVICES=""
python train_model.py ...
```

### Out of Memory
```bash
# Reduce batch size
python train_model.py --batch_size 16

# Or reduce samples
python train_model.py --samples_per_class 500
```

### Slow Training
```bash
# Reduce epochs
python train_model.py --epochs 20

# Use smaller dataset
python train_model.py --samples_per_class 500
```

## 💡 Pro Tips

1. **Start Small**: Train with 500 samples/class first to verify everything works
2. **Monitor Logs**: Check `logs/` directory for detailed training logs
3. **Save Checkpoints**: Models auto-save to `saved_models/` directory
4. **GPU Training**: Training is 10-50x faster on GPU
5. **Batch Size**: Increase if you have more RAM/GPU memory
6. **Early Stopping**: Let it work - it saves best model automatically
